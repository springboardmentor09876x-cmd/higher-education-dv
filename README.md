# EduVision_DV — Higher Education Performance Dashboard

## 📊 Project Overview

**EduVision_DV** is an interactive higher education analytics dashboard suite developed using **Tableau** and **Python**.

The project integrates university ranking and performance datasets from sources such as **QS World University Rankings** and **Times Higher Education** to provide insights into:

- University rankings and institutional performance
- Research impact and productivity
- Student diversity and internationalization
- Faculty-to-student ratios
- Country and regional education performance
- Global higher education trends

The final deliverable is a unified Tableau workbook containing four interconnected dashboards.

---

## 🎯 Project Objectives

The project aims to transform raw higher education data into meaningful and interactive visual insights for:

- Students
- Researchers
- University administrators
- Policymakers
- Education consultants

The dashboard enables users to compare universities, analyze research performance, evaluate student diversity, and benchmark countries and regions.

---

## 🖥️ Dashboard Suite

EduVision_DV consists of four interconnected Tableau dashboards.

### 1. University Overview

Provides an overview of global university performance.

**Key analysis:**
- Top university rankings
- Global university distribution
- Academic reputation
- University performance trends
- Institutional comparison

---

### 2. Research Analytics

Focuses on research performance across universities.

**Key analysis:**
- Research performance
- Citation performance
- Research productivity
- Research impact comparison
- Top research institutions

---

### 3. Student Analytics

Analyzes student-related higher education indicators.

**Key analysis:**
- International student analysis
- Faculty-to-student ratio
- Student diversity
- Enrollment comparisons
- Student distribution

---

### 4. Country Comparison

Provides country- and region-level benchmarking.

**Key analysis:**
- Country ranking comparison
- Education performance benchmarking
- Regional education trends
- Top-performing countries

---

## 📈 Key Performance Indicators

The project includes the following education KPIs:

| KPI | Description |
|---|---|
| Global Ranking Score | Represents overall university ranking performance |
| Research Impact Score | Measures research-related institutional impact |
| Faculty-to-Student Ratio | Indicates student-to-faculty relationship |
| International Student Percentage | Measures the proportion of international students |
| Academic Reputation Score | Represents academic reputation performance |
| Research Productivity Index | Represents research productivity |
