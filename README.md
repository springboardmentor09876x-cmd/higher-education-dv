# EduVision_DV – Higher Education Performance Dashboard

## Project Overview

EduVision_DV is a higher education analytics dashboard suite built with Python and Power BI. It transforms global university ranking data into an interactive dashboard suite for analyzing university rankings, research performance, student demographics, and country-level education trends.

## Project Statement

Using publicly available datasets such as QS World University Rankings and Times Higher Education World University Rankings, this project transforms raw educational data into actionable insights through an interactive Power BI workbook. It helps students, researchers, university administrators, policymakers, and education consultants evaluate institutional performance, compare universities globally, and identify trends in higher education.

## Dashboards

The final deliverable is a unified Power BI workbook (`EduVision_DV.pbix`) with four interconnected dashboards:

1. **University Overview** — Top university rankings, global distribution, academic reputation, performance trends, and institutional comparison.
2. **Research Analytics** — Publications analysis, citation performance, research productivity trends, top research institutions, and research impact comparison.
3. **Student Analytics** — International student analysis, faculty-to-student ratio, student diversity trends, and enrollment comparisons.
4. **Country Comparison** — Country ranking comparison, education performance benchmarking, and regional education trends.

## Features

- 4 interactive, interconnected dashboards
- Global filters: Year, Region, Country, Subject Area (synced across all pages)
- Navigation menu to move between dashboards
- 6 KPI cards per dashboard (24 total)
- Interactive charts, tables, and comparisons
