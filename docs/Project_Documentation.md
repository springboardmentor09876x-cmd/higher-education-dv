Project Title

EduVision – Higher Education Performance Dashboard

1. Project Overview

Explain:

EduVision is an interactive higher education analytics dashboard developed to analyze university performance using academic, research, ranking, and student-related metrics.

2. Objective
Analyze university performance
Compare universities and countries
Analyze research performance
Analyze student population and diversity
Provide interactive dashboards for decision-making
3. Data Sources

Mention your datasets:

QS World University Rankings
THE World University Rankings
Top 1000 Universities dataset
Other university/student datasets used in your project
