| KPI                              | Calculation                             | Unit     |
| -------------------------------- | --------------------------------------- | -------- |
| Total Universities               | `COUNTD(University ID)`                 | Count    |
| Countries Covered                | `COUNTD(Country)`                       | Count    |
| Avg Academic Reputation          | `AVG(Academic Reputation Score)`        | Score    |
| Avg Overall Score                | `AVG(Overall Score)`                    | Score    |
| Avg Global Ranking Score         | `AVG(Global Ranking Score)`             | Score    |
| Faculty-to-Student Ratio         | `AVG(Faculty Student Ratio KPI)`        | Ratio    |
| Student Population               | `SUM(Student Population)`               | Students |
| International Student Percentage | `AVG(International Student Percentage)` | %        |
| Avg Research Impact              | `AVG(Research Impact Score)`            | Score    |
