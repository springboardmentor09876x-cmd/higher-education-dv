# EduVision_DV — Dashboard Guide

EduVision_DV consists of four interconnected Tableau dashboards designed
to analyze higher-education performance from university, research, student,
and country perspectives.

---

## 1. University Overview

### Purpose

Provides a high-level view of university performance and global rankings.

### Main analyses

- Top overall ranked universities
- Global university distribution
- Academic reputation
- University performance trends
- Institutional performance comparison

### Key KPIs

- Global Ranking Score
- Academic Reputation Score
- Research Impact Score

### Interactions

Users can use the available filters to narrow the analysis by relevant
geographic and institutional dimensions.

---

## 2. Research Analytics

### Purpose

Analyzes research performance and research-related institutional indicators.

### Main analyses

- Publications performance
- Citation performance
- Research productivity trends
- Top research institutions
- Research impact comparison

### Key KPIs

- Research Impact Score
- Research Productivity Index

### Interactions

Users can filter and compare research performance across universities
and regions.

---

## 3. Student Analytics

### Purpose

Analyzes student diversity and faculty-to-student characteristics.

### Main analyses

- International student analysis
- Faculty-to-student ratio analysis
- Student diversity trends
- Student distribution analysis

### Key KPIs

- International Student Percentage
- Faculty-to-Student Ratio

### Interactions

Users can filter the dashboard to compare student-related indicators
across countries, regions, and institutions.

### Data limitation

A reliable, directly comparable enrollment measure was not available
across all integrated institutions. Therefore, enrollment was not
presented as a standalone KPI where the available data could produce
misleading comparisons.

---

## 4. Country Comparison

### Purpose

Compares higher-education performance across countries and regions.

### Main analyses

- Country ranking comparison
- Education performance benchmarking
- Regional education trends
- Top performing countries

### Key KPIs

- Global Ranking Score
- Academic Reputation Score
- Research Impact indicators

### Interactions

Users can compare countries and regions using interactive filters
and dashboard navigation.

---

## Dashboard Navigation

The four dashboards are connected through Tableau navigation controls.

Users can move between:

1. University Overview
2. Research Analytics
3. Student Analytics
4. Country Comparison

Filters and dashboard interactions allow users to explore the dataset
from different analytical perspectives.

---

## Recommended Usage

1. Start with **University Overview** for a general performance summary.
2. Use **Research Analytics** to investigate research performance.
3. Use **Student Analytics** to investigate internationalization and
   faculty-to-student indicators.
4. Use **Country Comparison** for country and regional benchmarking.
