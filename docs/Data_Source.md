# Dataset Sources

## 1. Dataset Overview

The University Ranking Analytics project uses the final university dataset for analyzing university rankings, academic performance, research productivity, student information, and country-wise educational performance.

**Dataset Name:** University Final Dataset

**File:** `university_final_dataset.xlsx`

**Rows:** 22,125

**Columns:** 44

**Sheet:** Sheet1

## 2. Dataset Purpose

The dataset is used to:

- Analyze university rankings
- Compare university performance
- Calculate educational KPIs
- Analyze academic reputation
- Analyze research productivity
- Compare countries and universities
- Analyze student-related metrics
- Build interactive Power BI dashboards

## 4. Data Preparation

The final dataset contains the fields required for university ranking analysis, educational metrics, research analysis, student analysis, and dashboard KPIs.

The dataset was used as the final data source for the Power BI dashboards.

## 5. Dashboard Usage

The final dataset supports the following dashboard analysis:

- University Overview
- Country Comparison
- Research Analytics
- Student Analytics

## 6. Dataset Quality

The final dataset was used for dashboard development and testing. The required fields for KPI calculations, rankings, filters, tables, charts, and other dashboard visualizations are included in the dataset.
