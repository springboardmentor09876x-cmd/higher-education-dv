# EduVision — Dashboard Testing Report

## 1. Report Purpose

This report documents the testing and validation performed for the EduVision Power BI dashboard suite as part of Module 7.

The objective was to verify the analytical KPIs, dashboard pages, interactions, filters, navigation, and presentation of the completed dashboard suite.

## 2. Project Scope

The testing covered the four completed dashboards:

1. University Overview
2. Research Analytics
3. Student Analytics
4. Country Comparison

The project data scope covers **2017–2026**.

## 3. Testing Areas

### 3.1 KPI Validation

The following KPI areas were validated:

- Global Ranking Score
- Research Impact Score
- Faculty-to-Student Ratio
- International Student Percentage
- Academic Reputation KPI
- Research Productivity Index

Validation focused on the implemented KPI logic and the effect of the active dashboard filter context.

### 3.2 Ranking and Comparison Validation

Ranking and comparison visuals were reviewed to ensure that the intended ranking-oriented measures and comparison dimensions were represented correctly within the dashboard context.

### 3.3 Dashboard Validation

Each dashboard was reviewed for its intended analytical purpose:

- **University Overview:** institutional performance, rankings, geographic distribution, trends, and comparison.
- **Research Analytics:** research performance, impact, and productivity.
- **Student Analytics:** student population, student-to-staff/faculty relationship, international students, diversity, and enrollment.
- **Country Comparison:** country and regional benchmarking and ranking comparison.

### 3.4 Interaction Validation

The following interaction areas were tested:

- Page navigation
- Dashboard linking
- Global filters
- Slicers
- Cross-filtering
- Drill-down interactions
- Visual selections
- Filter/reset behaviour

### 3.5 Presentation Validation

The dashboards were reviewed for:

- KPI readability
- Appropriate number formats
- Visual labels and titles
- Geographic visual rendering
- Table/comparison readability
- Consistency across dashboard pages
- Overall dashboard usability

## 4. QA Outcome

The project README records Module 7 — Testing & Validation as completed. The associated QA checklist records completion across the KPI, dashboard, interaction, filtering, navigation, and presentation validation areas.

No unsupported numerical test score or pass-rate is reported here; the report records the completed validation scope rather than inventing an execution statistic.

## 5. Final Result

**Module 7 — Testing & Validation: ✅ Completed**

EduVision completed the planned testing and validation stage and progressed to Module 8 documentation and final project delivery.

## 6. Maintenance

Any future change to the dataset, KPI measures, Power BI model, dashboard visuals, filters, or navigation should be followed by regression testing using the QA checklist.
