# EduVision – Dashboard Guide

## 1. Introduction

The EduVision dashboard suite provides interactive analysis of higher education performance.

The dashboard suite contains:

1. University Overview
2. Research Analytics
3. Student Analytics
4. Country Comparison

---

## 2. University Overview

The University Overview dashboard provides a high-level summary of university performance.

### Main Analysis

- University rankings
- University distribution
- Academic performance
- Research performance
- University comparison

### Filters

Users can filter the dashboard using available fields such as:

- Country
- Region
- University
- University Type

### How to Use

1. Select a country or region from the filter.
2. Select a university if a specific university needs to be analyzed.
3. Review the KPI values.
4. Compare the displayed universities.
5. Select charts to explore the data.

---

## 3. Research Analytics

The Research Analytics dashboard focuses on research performance.

### Main Analysis

- Research impact
- Research output
- Citation performance
- Research productivity
- Top research institutions

### How to Use

1. Apply the required filters.
2. Review research KPIs.
3. Compare universities.
4. Select a university or chart to explore research performance.

---

## 4. Student Analytics

The Student Analytics dashboard focuses on student-related performance.

### Main Analysis

- Student population
- International student percentage
- International student ratio
- Faculty-to-student ratio
- Student diversity
- Enrollment comparisons

### How to Use

1. Select Country, Region or University.
2. Review student-related KPIs.
3. Compare international student participation.
4. Review enrollment comparisons.
5. Use chart selections to explore the results.

---

## 5. Country Comparison

The Country Comparison dashboard compares higher education performance between countries.

### Main Analysis

- Country Ranking Comparison
- Education Performance Benchmarking
- Regional Education Trends
- Top Performing Countries
- International Student Ratio

### How to Use

1. Select a country if a specific country needs to be analyzed.
2. Select a region to compare regional performance.
3. Select University Type when required.
4. Review the ranking and education performance charts.
5. Compare countries using the displayed values.

---

## 6. Dashboard Filters

The dashboards use interactive filters.

Common filters include:

- Country
- Region
- University
- University Type

Changing a filter updates the relevant dashboard visualizations.

---

## 7. Dashboard Navigation

Users can navigate between the main dashboards:

University Overview
→ Research Analytics
→ Student Analytics
→ Country Comparison

---

## 8. Interacting with Charts

Users can:

- Hover over marks to view tooltips.
- Select bars to highlight data.
- Apply filters.
- Compare values across categories.
- Use dashboard navigation controls.

---

## 9. Notes

The displayed results depend on the records available in the final dataset.

Some visualizations may show different numbers of categories when filters are applied.
