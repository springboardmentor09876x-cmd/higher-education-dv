# Dashboard Guide

## 1. Overview

The University Ranking Analytics Dashboard is an interactive Power BI dashboard designed to analyze university rankings, academic performance, research productivity, student information, and country-level educational performance.

Users can interact with the dashboards using slicers and visual selections.

---

## 2. Dashboard 1 – University Overview

### Purpose

Provides an overall view of university performance.

### Main KPIs

- Average International Student Ratio
- Countries Covered
- Total Universities
- Average Academic Reputation
- Average Overall Score
- Average Research Productivity

### Main Visuals

- Academic Reputation Analysis
- Top 10 Universities by Overall Score
- University Performance Trends
- Global University Distribution
- University Academic Reputation Table

### Filters

The dashboard provides filters for:

- Country
- Year
- University Name

### How to Use

1. Select a country from the Country filter.
2. Select a year from the Year filter.
3. Select a university if required.
4. Observe how the KPI cards and visuals update.
5. Select a visual element to cross-filter related visuals.

---

## 3. Dashboard 2 – Country Comparison

### Purpose

Compares university performance across countries.

### Main Visuals

- Country Ranking Comparison
- Top Performing Countries
- Average Overall Score by Country
- Country-level performance comparison

### Filters

Users can filter the dashboard using available country and year selections.

### How to Use

1. Select a country or group of countries.
2. Compare their average overall scores.
3. Identify the highest-performing countries.
4. Use the visual interactions to analyze country-level differences.

---

## 4. Dashboard 3 – Research Analytics

### Purpose

Analyzes university research performance and research productivity.

### Main KPIs

- Total Publications
- Total Citations
- Average H Index
- Average Research Productivity
- Average Citations per Faculty

### Main Visuals

- Top 10 Research Institutions
- Research Productivity Comparison
- Publications and Citations Analysis
- Research Performance by Country
- Research-related comparison tables

### How to Use

1. Select the required country or year.
2. Review research KPIs.
3. Compare research institutions using ranking visuals.
4. Use charts and tables to analyze research performance.

---

## 5. Dashboard 4 – Student Analytics

### Purpose

Analyzes student population, international students, faculty-to-student ratio, and student diversity.

### Main KPIs

- Total Students
- Total International Students
- Average Faculty Student Ratio
- Average International Student Percentage

### Main Visuals

- Enrollment Comparisons
- Student Diversity Trends
- International Student Analysis
- Faculty-to-Student Ratio Analysis
- Global Student Distribution

### Filters

- Country
- Year
- University Name

### How to Use

1. Select the required country.
2. Select the required year.
3. Select a university if required.
4. Review student-related KPI cards.
5. Compare enrollment, international students, and faculty-to-student ratios.

---

## 6. Dashboard Filters

The dashboards use interactive filters to allow users to analyze specific portions of the dataset.

### Country Filter

Filters dashboard results based on the selected country.

### Year Filter

Filters dashboard results based on the selected year.

### University Name Filter

Filters results for a particular university.

---

## 7. Visual Interactions

Power BI visual interactions allow users to select a data point in one visual and observe the corresponding changes in other visuals.

For example:

- Selecting a country updates related KPI values.
- Selecting a year changes the corresponding trend data.
- Selecting a university updates university-specific information.

---

## 8. KPI Cards

KPI cards provide a quick summary of important university performance indicators.

Examples include:

- Total Universities
- Countries Covered
- Average Overall Score
- Average Academic Reputation
- Average Research Productivity
- Total Students
- Total International Students

---

## 9. Ranking Visuals

Ranking charts are used to identify high-performing universities, research institutions, and countries.

Examples include:

- Top 10 Universities by Overall Score
- Top 10 Research Institutions
- Top Performing Countries
- Country Ranking Comparison

---

## 10. Map Visuals

Map visuals show the geographical distribution of universities and students.

Users can use the map to understand the global distribution of universities and educational data.

---

## 11. General Usage Steps

1. Open the required dashboard.
2. Review the KPI cards.
3. Use the available filters.
4. Analyze the charts and tables.
5. Select visual elements for interactive filtering.
6. Compare universities, countries, years, and educational metrics.
7. Reset filters when a new analysis is required.

---

## 12. Dashboard Navigation

The dashboard pages are organized according to the analysis area:

| Dashboard | Main Focus |
|---|---|
| University Overview | Overall university performance |
| Country Comparison | Country-wise comparison |
| Research Analytics | Research performance |
| Student Analytics | Student and faculty metrics |
