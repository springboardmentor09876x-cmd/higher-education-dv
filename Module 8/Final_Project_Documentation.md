# EduVision_DV – Final Project Documentation

## Project Overview
EduVision_DV is a higher-education analytics dashboard suite designed to analyze university rankings, research performance, student characteristics and country-level educational trends.

## Objectives
- Compare university performance across ranking sources.
- Analyze research output and research impact.
- Examine student and international-student indicators.
- Compare higher-education performance across countries.
- Present insights through interactive dashboards.

## Data Sources
The project uses higher-education datasets including:
- QS World University Rankings
- Times Higher Education rankings
- CWUR rankings
- Student-related higher-education data

## Final Dataset
`datasets/processed datasets/university_final_dataset (1).xlsx`

Validated shape: **668 rows × 44 columns**.

## Dashboard Suite
1. University Overview
2. Research Analytics
3. Student Analytics
4. Country Comparison

## KPI Suite

- Research Impact Score
